# Katalog na klatki (frames)

Wrzuc tutaj swoje zdjecia, z ktorych ma powstac animacja GIF.

Wazne:

- Nazwij pliki tak, aby sortowaly sie w odpowiedniej kolejnosci, np.
  `1.jpg`, `2.jpg`, `3.jpg` (albo `01.jpg`, `02.jpg`, ...).
- Obslugiwane formaty: `.jpg`, `.jpeg`, `.png`, `.webp`.
- Najlepiej, gdy wszystkie zdjecia maja te sama orientacje i podobne
  kadrowanie - przejscia beda wtedy wygladaly najplynniej.

Nastepnie z katalogu glownego projektu uruchom:

```bash
tools/make_gif.sh
```

Wynik pojawi sie jako `out.gif`.
